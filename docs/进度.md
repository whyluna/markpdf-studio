## 已知限制与偏差

1. **波浪线（FR-4.1）**：PDFKit 不支持 Squiggly，已从工具条移除（Ink 模拟方案弃用）。
2. **便签（FR-4.2）**：用户决定不做，需求与实现整体移除（含 AnnotationKind.note）。
3. **图形标注（FR-4.3）**：用户决定精简为「批注」一种（页边文本框 + 虚线连接器）；手绘/矩形/箭头不做，对应枚举已删除。
3b. **mermaid（FR-2.4）**：用户决定不做（体积最大、集成最复杂）；FR-2.4 其余三项（公式/脚注/高亮）已实现。
4. **标签切换撤销栈**：换档即重置内核撤销历史（修复跨文档 ⌘Z 串档后正式生效——切回不保留 ⌘Z，但内容经 0.5s 自动保存绝不丢失）；按文档保留撤销历史可后续评估（内核 EditorState 池 / 多 WebView 池）。
5. **分栏双 PDF**：缩放/搜索/标注列表与写回均作用于最近点击的视图（标注 Store 跟随焦点仲裁，切换前先落盘旧文档）。
6. ~~**CI**~~：已启用（`.github/workflows/macos.yml`，2026-07-21）。
7. **FR-1.6 偏差**：侧栏宽度与分栏比例不持久（macOS 13 无宽度观测 API）；草稿内容不持久。
8. **FR-3.6 偏差**：夜间主题为图层滤镜方案（非内容流级反色），极端彩色图可能轻微失真。
9. **导出 HTML 分享**：KaTeX 样式依赖 file:// bundle 路径（本机查看正常，分享他机公式样式丢失）。
10. **md 查找栏样式**：为保留 CodeMirror 查找/替换/正则/整词功能，仅 CSS 美化向 PDF 栏靠拢，非像素级一致（无放大镜图标与 x/n 计数——那需自绘面板重做）。
