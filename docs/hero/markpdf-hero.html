2.2  PagedAttention

PagedAttention is an attention algorithm designed for efficient inference with long sequences. It manages the KV cache in fixed-size blocks and maps logical blocks to physical blocks.

The key idea is to treat the KV cache as a collection of blocks. Each block stores a contiguous chunk of tokens. Blocks are fetched on demand and assembled into a logical sequence.
