## 1. 产品概述

### 1.1 一句话定位
面向「读论文/文档 + 做笔记」场景的 macOS 原生工作台：在一个窗口内完成 **管理文件 → 阅读并标注 PDF → 编写 Markdown 笔记 → 双向关联** 的完整闭环。

### 1.2 目标用户
- 研究生、科研人员：大量阅读 PDF 论文，需要高亮批注并沉淀为结构化笔记
- 开发者、文字工作者：需要 Typora 级体验的 Markdown 写作工具
- 共同特征：文件散落在本地文件夹，厌恶重型文献管理软件的复杂度

### 1.3 核心价值与差异化
| 维度 | 市面现状 | 本产品 |
|---|---|---|
| Markdown 编辑 | Typora 体验好但无 PDF、无项目管理 | 同等 WYSIWYG 体验 + 完整文件树 |
| PDF 标注 | PDF Expert/Skim 无笔记联动 | 标注一键沉淀为 Markdown 笔记 |
| 知识管理 | Obsidian 编辑器半吊子、PDF 只读 | 真 WYSIWYG + 学术级 PDF 标注 |
| 项目管理 | VS Code 太重、非阅读向 | 轻量 Vault，打开文件夹即用 |

### 1.4 设计原则
1. **文件即真相**：md 存纯文本源码、PDF 标注写回标准 PDF Annotation，不使用私有数据库锁死用户数据
2. **单机离线**：不联网、无账号、无遥测
3. **键盘可达**：核心操作均有快捷键与命令面板入口
4. **原生体验**：遵循 macOS HIG，系统级渲染性能

## 2. 名词约定

| 名词 | 含义 |
|---|---|
| 工作区（Vault） | 用户打开的一个本地文件夹，作为内容管理单元 |
| WYSIWYG | 所见即所得编辑模式：光标所在块显示源码，其余块实时渲染 |
| 标注（Annotation） | PDF 上的高亮、下划线、便签等标准 PDF 注释对象 |
| 回链 | Markdown 中指向某 PDF 某页的链接，点击跳转 |
| 侧car（Sidecar） | 与原文件同名的 `.json` 附属文件，存放只读模式下的标注与元数据 |

## 3. 用户场景

### 场景 A：精读论文并做笔记（主场景）
小王打开 `论文阅读` 文件夹作为工作区 → 双击 `vllm.pdf` 在第 3 页高亮三段核心论述并写了一条便签 → 点击分栏，右侧自动打开关联笔记 → 点「导出标注」，三处高亮按页码整理进 `KV Cache 调研笔记.md` 并附带页码回链 → 在笔记中点击回链，跳回 PDF 第 3 页原文位置。

### 场景 B：纯 Markdown 写作
新建 `组会汇报.md`，以所见即所得模式写作：插入对比表格、行内公式、代码块；从大纲面板拖拽调整章节顺序；导出 PDF 发给导师。

### 场景 C：批注后分享
对合作方发来的 PDF 做高亮与文字批注，标注直接写回文件，对方用 Adobe/预览打开即可看到全部批注。

## 4. 功能需求

优先级定义：**P0** = MVP 必需（M1 交付）；**P1** = V1.0 必需（M2/M3 交付）；**P2** = V1.x 增强。

### 模块 1：文件与项目管理

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-1.1 | 打开本地文件夹作为工作区，递归展示 `.md` / `.pdf` / 常见图片 | P0 | 1000 个文件的目录树首次加载 < 500ms |
| FR-1.2 | 文件树操作：新建文件/文件夹、重命名、删除（移入系统废纸篓）、拖拽移动、右键菜单 | P0 | 全部操作可 Cmd+Z 撤销；删除可从废纸篓恢复 |
| FR-1.3 | FSEvents 监听外部变更，树自动刷新 | P0 | 在 Finder 中增删文件，树 1s 内同步 |
| FR-1.4 | 标签页：打开/关闭/中键关闭/拖拽重排；拖拽至边缘分栏（左右双栏） | P0 | 交互对齐设计稿；分栏比例可拖动调节 |
| FR-1.5 | 收藏夹、最近打开（最多 20 条） | P1 | 重启后保留 |
| FR-1.6 | 工作区状态持久化：打开的标签、分栏状态、侧栏宽度、各文件阅读/编辑位置 | P1 | 重启应用完整恢复现场 |

### 模块 2：Markdown 编辑与阅读（对标 Typora）

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-2.1 | 所见即所得编辑：光标所在块显示源码、离块即渲染 | P0 | 交互手感与 Typora 一致，无输入延迟（键入到渲染 < 16ms） |
| FR-2.2 | 三种模式切换：WYSIWYG / 纯源码 / 只读阅读 | P0 | 切换不丢失光标位置与撤销栈 |
| FR-2.3 | GFM 全集：标题、列表、表格、任务列表、代码块（语法高亮）、引用、分割线、链接、图片 | P0 | CommonMark + GFM 规范测试集通过 |
| FR-2.4 | 扩展语法：KaTeX 行内/块级公式、mermaid 图、脚注、高亮 `==text==` | P1 | 渲染正确，编辑态不抖动 |
| FR-2.5 | 图片管理：粘贴/拖拽图片自动存入工作区 `assets/` 并插入相对路径 | P1 | 移动 md 文件后相对链接自动修正 |
| FR-2.6 | 大纲 TOC 面板：层级展示、点击跳转、拖拽调整章节顺序（自动移动源码块） | P0 | 与文档结构实时同步 |
| FR-2.7 | 自动保存（防抖 500ms 落盘）+ 崩溃恢复 | P0 | 强杀进程后丢失内容不超过最后一次击键 0.5s |
| FR-2.8 | 字数/字符统计、预计阅读时长，显示于状态栏 | P1 | 实时更新 |
| FR-2.9 | 导出：PDF（CSS 主题排版）、HTML | P1 | 导出 PDF 排版与编辑态渲染一致 |
| FR-2.10 | 打字机模式（当前行垂直居中）、专注模式（高亮当前段落） | P2 | 可分别开关 |

### 模块 3：PDF 阅读（对标 PDF Expert）

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-3.1 | PDFKit 渲染；视图模式：连续滚动 / 单页 / 双页 | P0 | 500 页文档打开 < 1s，滚动满 60fps |
| FR-3.2 | 缩放：50%–400%，适应宽度 / 适应页面 / 实际大小，支持 Cmd+滚轮与触控板捏合 | P0 | 缩放后保持当前页视口位置 |
| FR-3.3 | 文档大纲（outline）跳转、用户自定义书签、缩略图侧栏 | P0 | 与设计稿右侧面板一致 |
| FR-3.4 | 页内搜索：结果高亮、计数、Cmd+G 下一个 | P0 | 500 页全文搜索 < 2s |
| FR-3.5 | 每个文件记住上次阅读位置与缩放 | P1 | 重开自动恢复 |
| FR-3.6 | 阅读主题：白天 / 羊皮纸 / 夜间（智能反色、图片不反色） | P2 | 切换即时生效不重排 |

### 模块 4：PDF 标注（对标 Skim / PDF Expert）

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-4.1 | 文本标注：高亮、下划线、删除线、波浪线；划词弹出浮动工具条 | P0 | 选区贴合文本基线，多行选区正确分段 |
| FR-4.2 | 便签（页边图标 + 弹出批注框） | P0 | 悬停预览、点击编辑 |
| FR-4.3 | 图形标注：文本框、手绘、矩形/箭头 | P1 | 矢量存储，缩放不失真 |
| FR-4.4 | 颜色系统：4 色快捷切换，每种标注类型记忆最近用色 | P0 | 工具栏与设计稿一致 |
| FR-4.5 | 标注列表面板：按页/颜色/类型排序筛选，点击定位并闪烁提示，支持改名与删除 | P0 | 与文档实时同步 |
| FR-4.6 | 标注写回 PDF 文件本体（标准 Annotation，第三方阅读器可见）；写回前自动创建一次性 `.bak` 备份 | P0 | 用 macOS 预览打开标注完整可见 |
| FR-4.7 | 只读模式：不修改原文件，标注存同名 sidecar JSON | P1 | 模式可逐文件切换 |
| FR-4.8 | 导出全部标注为 Markdown：按页分组，格式 `- [p.N] 摘录`，追加写入目标笔记 | P1 | 增量导出可去重 |

## 5. 非功能需求

| 编号 | 类别 | 指标 |
|---|---|---|
| NFR-1 | 性能 | 冷启动 < 1.5s；100 页 PDF 打开 < 1s；滚动 60fps；单 md 文件 2MB 内编辑无卡顿 |
| NFR-2 | 兼容 | macOS 13+；Apple Silicon 原生，Intel 兼容 |
| NFR-3 | 内存 | 打开 500 页 PDF + 20 个标签页，常驻内存 < 500MB |
| NFR-4 | 数据安全 | 无任何网络请求与遥测；删除走废纸篓；标注写回前自动备份；崩溃不丢稿（FR-2.7） |
| NFR-5 | 稳定性 | 会话崩溃率 < 0.1%；所有文件操作异常有用户可读提示 |
| NFR-6 | 安装分发 | 开发者签名 + 公证，DMG 拖拽安装，体积 < 40MB |

## 6. 界面设计基准

以 HTML 高保真设计稿（`prototype/index.html`）为**唯一视觉与交互基准**，关键规格：

| 元素 | 规格 |
|---|---|
| 窗口 | 圆角 12px，默认 1380×900，最小 1080×640 |
| 工具栏 | 高 52px；左：交通灯+侧栏开关+文档标题；右：搜索框（190px）→ 标注工具组（PDF 上下文显示）→ 分栏/导出/主题/右面板 |
| 左文件树 | 宽 238px；分区：工作区 / 收藏 / 最近打开 |
| 右面板 | 宽 266px；md 上下文=大纲+引用，pdf 上下文=缩略图/书签/标注 |
| 标签栏 | 高 34px，圆角上沿标签，可关闭 |
| 状态栏 | 高 29px；md 显示字数/模式，pdf 显示页码/缩放 |
| 主题色 | 系统蓝 `#0A84FF`；高亮黄 `#FFD43B`、绿 `#94D82D`、蓝 `#74C0FC`、红 `#FF8787` |

## 8. 风险与缓解

| 编号 | 风险 | 影响 | 缓解措施 |
|---|---|---|---|
| R1 | WYSIWYG 编辑器工作量失控 | 高 | 采用 WKWebView + CodeMirror 6 成熟内核（参考开源 MarkEdit 架构）；内核作为纯网页先行开发、浏览器内独立调试，达标后再嵌入 |
| R2 | PDFKit 超大文档渲染性能 | 中 | 异步预渲染视口前后各 2 页；后台线程栅格化缓存；Instruments 验证 |
| R3 | WebView ↔ Swift 桥接消息复杂度膨胀 | 中 | 单一 Bridge 通道 + 类型化消息协议（见开发规范 §3.4），禁止散点调用 |
| R4 | 无 macOS 构建环境导致原生层缺陷发现滞后 | 中 | GitHub Actions macOS runner 每次提交编译+单测；HTML 原型先行冻结交互；用户真机按验收清单回归 |
