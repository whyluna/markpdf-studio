# MarkPDF Studio 功能说明

> 面向使用者的功能与快捷键手册。适用版本 **0.1.0**。
> 视觉与交互基准见 [`prototype/index.html`](../prototype/index.html)；需求与开发规范见同目录其余文档。

MarkPDF Studio 是一款 macOS 原生的「Markdown + PDF」阅读编辑工作台：在一个窗口内完成 **管理文件 → 阅读并标注 PDF → 编写 Markdown 笔记 → 双向关联** 的闭环。所有数据留在本机，不联网、无账号、无遥测。

## 快捷键速查

### 全局 / 文件

| 快捷键 | 功能 |
|---|---|
| `⌘O` | 命令面板（搜索并执行任意功能） |
| `⌘⇧O` | 打开文件夹作为工作区 |
| `⌘P` | 快速打开（文件名模糊搜索） |
| `⌘⇧F` | 全文搜索（Markdown 正文 + PDF 文本） |
| `⌘S` | 立即保存当前 Markdown（平时 0.5 秒自动保存） |
| `⌘,` | 打开设置 |

### Markdown 编辑器

| 快捷键 | 功能 |
|---|---|
| `⌘Z` / `⌘⇧Z` | 撤销 / 重做（切换文件后历史重置，见[已知限制](#已知限制)） |
| `⌘F` | 编辑器内查找 |
| `⌘` + 点击 | 跳转链接：外部链接开浏览器、`#标题` 跳文内锚点、`xxx.pdf#page=N` 跳 PDF |
| 双击 | 图片 / 公式 / 脚注上标：进入源码编辑 |
| 点击脚注上标 `[n]` | 跳到文末对应参考文献；文献行尾 `↩` 跳回首处引用 |
| `⌘C` `⌘V` `⌘X` `⌘A` | 标准复制 / 粘贴 / 剪切 / 全选（粘贴图片自动存入 `assets/`） |

### PDF 阅读 / 标注

| 快捷键 | 功能 |
|---|---|
| `⌘F` | 页内查找 |
| `⌘G` / `⌘⇧G` | 查找下一个 / 上一个（焦点在 PDF 上按 `Esc` 退出查找） |
| `⌘=` / `⌘-` / `⌘0` | 放大 / 缩小 / 实际大小（PDF、图片通用） |
| `⇧⌘C` | 把 PDF 选中文字复制为「带页码回链的引用块」 |
| `Esc` | 取消当前标注工具 / 关闭查找栏 |

> 提示：几乎所有功能都能在命令面板（`⌘O`）里搜到并执行，支持标题与**拼音首字母**匹配（如输入 `qwss` 找「全文搜索」）。

## 文件与工作区

- **打开工作区**：`⌘⇧O` 选择一个本地文件夹，左侧文件树递归展示其中的 `.md` / `.pdf` / 常见图片（png、jpg、gif、webp、svg、heic、tiff、bmp）。
- **文件树操作**：右键菜单或顶部 `+` 进行 新建文件 / 新建文件夹 / 重命名 / 删除（移入系统废纸篓）/ 在 Finder 中显示；支持拖拽移动；文件操作可 `⌘Z` 撤销。
- **外部变更自动刷新**：在 Finder 里增删改，文件树约 1 秒内同步。
- **标签页与分栏**：点击文件在标签页打开；拖标签到窗口右缘或点工具栏分栏按钮，可左右双栏对照（例如左 PDF、右笔记）。
- **收藏 / 最近打开**：文件树设「收藏」「最近打开」分区（最近打开保留最多 10 条），右键可加入收藏，重启保留。
- **恢复现场**：重启应用自动恢复上次打开的标签、分栏、各文件的阅读/编辑位置。

## Markdown 编辑

对标 Typora 的所见即所得体验，内核基于 CodeMirror 6。

### 三种模式（工具栏切换）

- **所见即所得**：光标所在块显示源码，离开即渲染。
- **源码**：始终显示纯 Markdown 源码。
- **阅读**：全文渲染、只读。

### 支持的语法（GFM 全集）

标题、**加粗**、*斜体*、~~删除线~~、`行内代码`、链接、图片、引用块、有序/无序列表、任务列表（可勾选）、表格、分割线、代码块（语法高亮）。

**代码块**：顶部语言栏可点击**下拉切换语言**（Python、JavaScript/TypeScript、JSON、YAML、Bash、C/C++、Java、Rust、Go、Swift、SQL、HTML、CSS），右上角**复制按钮**一键复制代码。

### 扩展语法

- **数学公式（KaTeX）**：行内 `$...$`、块级 `$$...$$`。
- **脚注**：`[^label]` 引用 + `[^label]: 内容` 定义；点上标跳到文末文献、文献行尾 `↩` 回跳首处引用。同一 `label` 多处引用共享同一编号。
- **高亮**：`==文字==` 黄色底纹。

> 注：公式 / 脚注 / 高亮在**表格单元格内**不渲染；mermaid 图表暂不支持。

### 其它

- **图片管理**：粘贴或拖拽图片自动存入工作区 `assets/` 并插入相对路径；移动 `.md` 文件时相对图片链接自动修正。
- **大纲面板**：右侧展示标题层级，点击跳转。
- **自动保存**：停止输入 0.5 秒自动落盘（原子写入）；文件名旁橙点表示有未保存改动。
- **字数统计**：状态栏实时显示字数 / 字符数 / 预计阅读时长。
- **导出**：导出为 PDF（真实分页）或 HTML。
- **打字机模式 / 专注模式**：设置面板开关——打字机让当前行垂直居中，专注压暗非当前段落。

## PDF 阅读

对标 PDF Expert 的阅读体验，基于系统 PDFKit。

- **视图模式**：连续滚动 / 单页 / 双页连续（可在设置里设默认值）。
- **缩放**：50%–400%，支持 `⌘=`/`⌘-`/`⌘0`、状态栏控件与触控板捏合。
- **侧栏**：缩略图、文档大纲（点击跳转）、用户书签（持久化）。
- **页内查找**：`⌘F` 打开查找栏，即输即搜、命中计数，`⌘G`/`⌘⇧G` 上下跳转，放大后也能精确定位到命中词。
- **阅读位置记忆**：每个文件记住上次页码与缩放，重开自动恢复。
- **阅读主题**：白天 / 夜间（夜间为智能反色，图片观感接近正常）。

## PDF 标注

对标 Skim / PDF Expert，标注写回**标准 PDF Annotation**——用系统「预览」或 Adobe 打开同样可见。

- **标注类型**：高亮、下划线、删除线、批注（页边图标 + 虚线连接到正文）。
- **划词标注**：选中工具后划词即标；或划词后用浮动工具条选择。
- **颜色系统**：黄 / 绿 / 蓝 / 红四色，每种标注类型各自记忆最近用色。
- **标注列表**：右侧面板列出全部标注，可按 页码 / 颜色 / 类型 排序，点击定位并闪烁提示，右键改名或删除。
- **写回与备份**：标注自动写回 PDF 文件；首次写回前创建一次性 `.bak` 备份。
- **只读模式**：可逐文件切换——标注存同名 `.json`（sidecar），不改动原 PDF。
- **导出标注**：一键把全部标注导出为 Markdown，按页分组、带页码回链，追加写入目标笔记并自动去重。

## Markdown × PDF 联动

- **分栏对照**：左 PDF、右笔记，独立滚动。
- **复制为引用**：在 PDF 选中文字按 `⇧⌘C`，生成「引用块 + 页码回链」，粘贴进 Markdown。
- **PDF 回链跳转**：Markdown 里 `[描述](xxx.pdf#page=N)`，`⌘`+点击打开该 PDF 并跳到对应页、整页短暂高亮。
- **反向链接面板**：Markdown 上下文的右侧面板展示「当前文件被哪些文件引用」，点击打开来源；大纲与反向链接之间的分界线可拖动调整。

## 搜索与命令面板

- **快速打开 `⌘P`**：文件名模糊匹配（子序列评分），万级文件秒开。
- **全文搜索 `⌘⇧F`**：同时搜 Markdown 正文与 PDF 文本层，带上下文摘录、命中计数，按相关度排序，点击跳转命中处。（查询需 ≥2 字符；扫描版无文本层的 PDF 搜不到。）
- **命令面板 `⌘O`**：搜索并执行任意功能，支持标题与拼音首字母匹配。

## 外观与设置

`⌘,` 打开设置面板：

- **编辑器字体**：系统默认 / 衬线 / 等宽。
- **字号**：13–20。
- **行高**：1.4–2.2。
- **PDF 默认视图**：连续滚动 / 单页 / 双页连续。
- **PDF 阅读主题**：白天 / 夜间。
- **打字机模式 / 专注模式**：分别开关。

明暗主题跟随系统外观自动切换。

## 已知限制

- **切换文件后撤销栈重置**：切到别的文件再切回，之前的 `⌘Z` 历史不保留（内容已自动保存，不会丢失）。
- **表格单元格内**不渲染公式 / 脚注 / 高亮；**mermaid** 图表不支持。
- **侧栏宽度、分栏比例、右面板分界比例**在重启后不保留（拖动调整仅当次有效）。
- **分栏双 PDF** 时，缩放 / 查找作用于最近点击的那一侧。
- **夜间阅读主题**为图层滤镜方案，极端彩色图片可能轻微失真。
- **导出的 HTML** 在他人机器打开时，KaTeX 公式样式可能丢失（本机查看正常；导出 PDF 无此问题）。
- 部分标注形态未做：波浪线、便签、手绘 / 矩形 / 箭头。
