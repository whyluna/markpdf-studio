KV Cache 调研笔记

更新于 2026-07-15 · 标签：#LLM推理 #KVCache #系统优化 · 关联文献：vllm.pdf、lmcache.pdf、mooncake.pdf

1. 背景与问题

自回归解码时，每步都要对历史所有 token 的 K/V 做注意力，因此把 KV Cache 驻留显存是避免重复计算的关键。但 KV Cache 的显存占用随 batch size × 序列长度 线性膨胀，很快成为吞吐瓶颈。

编辑中 · 当前段显示源码**PagedAttention** 借鉴操作系统的 `虚拟内存 + 分页` 思想：把 KV Cache 切成固定大小的 block，再用 block table 做逻辑块 → 物理块的映射，从根上消除显存碎片。

2. vLLM：PagedAttention

  • 逻辑块连续、物理块离散，按需分配，显存浪费压到 < 4%
  • 共享前缀（system prompt / 并行采样）映射同一物理块，引用计数 + Copy-on-Write
  • 配套连续批处理（continuous batching），吞吐相比 HF 提升一个数量级
Attention(q, K, V) = softmax( q·KT / √d ) · V，按 block 分块计算
Python · 推理示例复制
from vllm import LLM, SamplingParams

llm = LLM(model="Qwen/Qwen2.5-7B", gpu_memory_utilization=0.9)

Woosuk Kwon, Zhuohan Li, Siyuan Zhuang, Ying Sheng, Lianmin Zheng, Cody Hao Yu,

4. PagedAttention

便签 · p.3
核心：逻辑块 → 物理块映射，完全类比 OS 页表。写笔记时重点对比 §4.2。

Inspired by the virtual memory and paging techniques in operating systems, we propose PagedAttention, an attention algorithm that allows storing continuous keys and values in non-contiguous memory space. Specifically, PagedAttention divides the request's KV cache into blocks, each of which can contain the attention keys and values of a fixed number of tokens. In PagedAttention, the blocks for the KV cache do not need to be contiguous in physical memory, which allows us to manage the KV cache in a more flexible way as in OS's virtual memory: one can think of blocks as pages, tokens as bytes, and requests as processes.

This design eliminates most memory waste: the internal fragmentation only happens at the last block of a request. As a result, the memory waste is limited to under 4%, turning into near-zero waste in KV cache memory. This empowers the serving system to batch more sequences together, increase GPU utilization, and thereby significantly improve the throughput, as we show in the evaluation results.
